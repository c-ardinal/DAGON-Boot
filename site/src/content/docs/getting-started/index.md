## ブラウザで

[DAGON Consoleのデモ](~/demo/)はブラウザの内部で動作します。対象は模擬のPC接続ノード1つと、その接続先のノード2つです。

1. サンプルから構成を作成します。
2. 「書込」に切替後に「接続する」をクリックします。
3. 「書込」をクリックすると、用意済の新規バージョンをノードへ書込します。

デモはファイルの読込と保存、機器への接続、キーの保持をしません。これらの操作部品をポイントすると、その理由を表示します。

## dagonコマンドで

`dagon`コマンドの[インストール](/getting-started/install/)を事前に実行します。

### `dagon sim`

```sh
dagon sim
```

シミュレータ上で一連のシナリオを実行します。

- 転送中に電断が発生する書込
- 未確定のイメージ
- 改ざんしたパッケージ
- 全消去したF401の、ROMブートローダ経由の復旧
