:::caution
As of November 8, 2026, this is an alpha that supports only three kinds of microcontroller, made for "Built with Claude: Japan 2026". Please understand that breaking changes may be made before the official release.
:::

Try DAGON Console in the browser: [the demo](~/demo/).

DAGON is for developers who build something out of a few microcontrollers
and want to keep improving it once it is in use. You choose the boards (or
just their MCUs), draw how they connect, and write your application in
Rust; DAGON gives every node a project that builds, and updates the whole
group safely: every image is signed, a node runs a new version on trial and
goes back to the previous one by itself when the new one is never
confirmed.

These pages are in four parts:

- [Getting started](/en/getting-started/): try DAGON and set it up.
- [How-to guides](/en/how-to/): steps for one task each.
- [Explanation](/en/explanation/): how DAGON works and why.
- [Reference](/en/reference/): every route, event, format and board,
  generated from DAGON's own sources.
