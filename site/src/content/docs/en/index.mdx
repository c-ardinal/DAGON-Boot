:::caution
As of November 8, 2026, this is an alpha that supports only three kinds of microcontroller, made for "Built with Claude: Japan 2026". Please understand that breaking changes may be made before the official release.
:::

Try DAGON Console in the browser: [the demo](~/demo/).

A beautiful design with a muddy operation: taking things apart, swapping
cables, one write tool per MCU, every time a program changes. DAGON makes the
distributed multi-microcontroller designs of professionals and specialists easy
for a wide range of people, from those starting electronics with AI to makers
who care for compactness and finish.

Before assembly, you write each node directly once. After that no write pattern
is touched and nothing is opened. Through the hub, however deep inside and
however many, writing is the same operation as one node. More nodes take more
time; the operation does not grow. Every image is signed, and a node runs a new
version on trial and goes back to the previous one by itself when it does not
work.

Mixed MCUs are handled by drawing the 構成 (the setup). Applications are Rust
only.
