1 つの作業ごとに手順をまとめています。
新しいプロジェクトから書き込みまでは[はじめから書き込みまで](/getting-started/first-project/)にあります。
ここの手順は、そこから先の作業です。

- [自分のボード（マイコンで選ぶ）](/how-to/own-board/): [一覧](/reference/boards/)に無いボードを使う
- [つながりを差し替える](/how-to/swap-link/): ノードのつながり方を変える
- [既にあるファームウェアに DAGON を組み込む](/how-to/existing-firmware/): `dagon new` で作っていないファームウェアに足す
- [マイコンとリンクを足す](/how-to/new-mcu-or-link/): DAGON に新しいマイコンやリンクを足す
- [プロジェクトでの Claude の手助け](/how-to/claude-help/): 新しいプロジェクトに入る Claude Code の指示とスキルを知る
