Try the [DAGON Console demo](~/demo/) in the browser.

A beautiful design with a muddy operation.
Every time a program changes, you take things apart, swap cables and use one write tool per MCU.

DAGON makes the distributed multi-microcontroller designs of professionals and specialists easy for a wide range of people, from those starting electronics with AI to individual developers who care for compactness and finish.

Before assembly, you write each node directly once.
After that no write pattern is touched and nothing is opened.
Through the hub on your PC, you write to the children beyond it with the same operation as one node.
More nodes take more time; the operation does not grow.

Every image is signed.
A node runs a new version on trial and goes back to the previous one by itself when it does not work.

Mixed MCUs are handled by drawing the 構成 (the setup).

Applications are written in Rust.

Words such as node and hub are in [What the words mean](/en/explanation/words/).
