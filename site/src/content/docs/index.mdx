[DAGON Console のデモ](~/demo/)をブラウザで試せます。

設計は美しいのに、運用が泥くさい。プログラムを直すたびに分解し、ケーブルをつなぎ替え、マイコンごとに別の書き込みツールを使うことになります。
DAGON は、プロや専門家が使う分散マイコンの設計を、AI と電子工作を始める人から、小ささや仕上がりにこだわるメーカーまで、幅広い人が扱えるようにします。

組み立てる前に、ノードごとに 1 度だけ直接書き込みます。その後は、書き込み用のパターンに触れることも、ケースを開けることもありません。
親機を通して、どれだけ奥にあっても、何台あっても、1 台のときと同じ操作で書き込めます。台数が増えて伸びるのは時間で、操作は増えません。
イメージはすべて署名付きです。ノードは新しいバージョンを試しに起動し、うまく動かなければ自分で前のバージョンに戻ります。

種類の違うマイコンが混ざっていても、構成を描くだけで扱えます。アプリは Rust だけです。
