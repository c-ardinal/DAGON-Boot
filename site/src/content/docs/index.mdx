[DAGON Console のデモ](~/demo/)をブラウザで試せます。

DAGON は、いくつかのマイコンを組み合わせて何かを作り、使い始めたあとも良くしていきたい開発者のためのものです。
ボード（またはそのマイコン）を選び、つなぎ方を描き、アプリを Rust で書きます。
DAGON は、ノードごとにビルドできるプロジェクトを用意し、全体を安全に書き換えます。
イメージはすべて署名付きです。ノードは新しいバージョンを試しに起動し、確定されなければ自分で前のバージョンに戻ります。

このページは 4 つに分かれています。

- [はじめに](/getting-started/): DAGON を試し、使えるようにします。
- [やり方](/how-to/): 1 つの作業ごとの手順です。
- [しくみ](/explanation/): DAGON がどう動くか、なぜそうなっているかです。
- [リファレンス](/reference/): ルート、イベント、形式、ボードの一覧です。DAGON 自身のソースから作っています。
