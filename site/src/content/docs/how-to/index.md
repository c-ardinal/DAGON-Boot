Each guide covers one task. The path from a new project to an update runs
through these, in this order:

1. [Start a project](https://github.com/c-ardinal/DAGON-Boot#1-start-a-project)
2. [Define the 構成 in DAGON Console](https://github.com/c-ardinal/DAGON-Boot#2-define-the-topology-in-dagon-console)
3. [Generate the node crates](https://github.com/c-ardinal/DAGON-Boot#3-generate-the-node-crates)
4. [Build](https://github.com/c-ardinal/DAGON-Boot#4-build)
5. [Write the first version](https://github.com/c-ardinal/DAGON-Boot#5-write-the-first-version-once-per-node)
6. [Update, and go back](https://github.com/c-ardinal/DAGON-Boot#6-update-and-go-back)

Using a board that is not in the [list](/reference/boards/):
[choose it by its MCU](https://github.com/c-ardinal/DAGON-Boot#your-own-board-chosen-by-mcu).
