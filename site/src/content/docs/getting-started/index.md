## ブラウザで

[DAGON Consoleのデモ](~/demo/)は、ブラウザの中で動きます。相手は模擬のPC接続ノード1つと、その接続先のノード2つです。

1. 見本から構成を作成します。
2. 「書込」に切り替えて「接続する」を押します。
3. 「書込」を押すと、用意してある新しいバージョンをノードへ書込します。

デモはファイルを読み書きせず、機器につながず、鍵を持ちません。これらの操作を指すと、理由を表示します。

## dagonコマンドで

先に`dagon`コマンドを[入れます](/getting-started/install/)。

### `dagon sim`

```sh
dagon sim
```

シミュレータ上で、通しのシナリオを実行します。

- 転送中に電断が起きる書込
- 確定しないイメージ
- 改ざんしたパッケージ
- 全消去したF401の、ROMブートローダ経由の復活
